# 模拟器管理

HiSH 支持创建多个模拟器实例，方便用户实现镜像制作、环境隔离等操作。同一时刻，用户可以选择任一实例运行。

在主界面下方选择“模拟器管理”即可进入“模拟器管理界面”，该界面展示了当前 HiSH 中的模拟器实例，并提供了 模拟器管理、镜像管理、共享文件夹管理
功能。

## 模拟器管理

模拟器管理界中，您可以点击标题栏右侧的“添加”按钮（PC则在列表下方），进入“编辑模拟器”界面，完成模拟器的基本配置后，即可点击“完成”完成模拟器创建。

在创建模拟器的界面中，可以设置：

* CPU核数：指定CPU核数
* 内存大小：指定内存大小
* 系统镜像：选择HiSH中已有的镜像创建模拟器
* 端口映射：将对主机端口的访问转发到模拟器端口中
* 只读共享文件夹
* init

在“模拟器管理”列表中，可以看到当前正在运行的模拟器实例，也可以其它点击卡片中的 “运行”
按钮启动其它模拟器，也可以直接将常用的模拟器实例设置为“默认启动”，即在HiSH启动时自动运行。

模拟器管理中还可以支持：

* 删除：删除模拟器实例及其对应的数据
* 复制：基于当前模拟器的配置和镜像复制一个新的模拟器实例
* 导出：保存将当前模拟器的文件系统镜像，用于后续创建新的模拟器时作为模板
* 修改：修改模拟器的运行设置，通常需要重启后才可生效

## 网页预览

手机可从虚拟键盘的设置菜单进入“网页预览”，平板 / PC 可使用顶部的“网页预览”按钮。在 HiSH 内访问 Web 服务时，应用可保持在前台。

例如：配置模拟器端口 `3080` → 主机端口 `8000`，保存并重启模拟器，在 Linux 中启动监听 `0.0.0.0:3080` 的服务，然后在预览页面输入 `http://127.0.0.1:8000`。页面支持输入地址、刷新、网页历史返回及映射端口快捷选择。

映射端口菜单显示当前模拟器配置中未被启动阶段跳过的主机端口，不检测该端口是否实际运行 HTTP 服务。修改端口映射后需重启模拟器再访问。

预览仅支持 HTTP / HTTPS，没有终端页面使用的原生 JavaScript 桥，也不自动打开其他应用、下载文件或跳过证书错误。打开网页仍受该服务的登录与认证要求约束。
